## Defects addressed during this work

- A pattern-cover CSS selector initially rotated the whole shelf card; the selector now targets only its artwork.
- A file input initially appeared as a stray control; it is now hidden behind the explicit import buttons.
- Mobile users needed a shorter path between a long editor and its preview; section links now provide it.
- Branching-story transitions now move keyboard focus to the new scene heading.
- Historical exports could otherwise be regenerated by a newer renderer. Checks now retain the exact HTML/SVG bytes and bind their hashes; history downloads use that snapshot.
- Draft export wording describes the available check without implying the draft has passed.

## Remaining limits

Prepared programs and bounded settings only. No AI inference, source uploads, arbitrary graphs, photos, cloud sync, user-project hosting, timers, or multiplayer. Editable JSON imports settings only; full history exports are not importable. One current editable draft per project, plus checked history. Playback restarts on reload.

Model checks cover declared discrete behavior, not beauty, fun, prose quality, print color, screen-reader conformance, hardware timing, or universal JavaScript correctness. Native browser 200% zoom, Safari/Firefox, touch hardware, physical printing, and a comprehensive accessibility audit remain unverified in this round. Small-screen reflow is not evidence of native zoom behavior. Actual first-time human comprehension remains to be observed.
